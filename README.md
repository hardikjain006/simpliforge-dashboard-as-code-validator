# Dashboard-as-code validator

Validate a dashboard defined as code against generated telemetry, and report
one actionable result in a CLI or on a static page.

- Public requirements contract: [docs/requirements.md](docs/requirements.md)
- Status: requirements only. No implementation exists yet.

## Goal

Build a "Dashboard-as-code validator" that reads generated telemetry and
produces one actionable validation result, delivered through a command-line
interface or a static page.
